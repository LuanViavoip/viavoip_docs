Autenticação

DEMONSTRAÇÃO. Fluxo de autenticação fictício. Não use estes endpoints.

As APIs demonstrativas usam um token de acesso enviado no cabeçalho Authorization. Veja os exemplos de requisição e resposta no painel à direita.

Passo a passo

  1. Solicite um token em POST https://api.example.com/demo/auth/token.
  2. Guarde o valor de access_token retornado.
  3. Envie Authorization: Bearer <token> nas próximas chamadas.

Códigos de resposta

StatusSignificado (exemplo)
200Token emitido
401Credenciais inválidas
429Muitas tentativas

Depois de autenticar, consulte a API de Clientes.
