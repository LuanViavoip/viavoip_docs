API de Clientes

DEMONSTRAÇÃO. Recursos e campos fictícios, sem relação com o Sol-Maker real.

A API demonstrativa de clientes permite consultar, criar e atualizar cadastros fictícios. Todas as chamadas exigem autenticação.

Operações

  • Consultar cliente
  • Criar cliente
  • Atualizar cliente
