DEMONSTRAÇÃO. Conteúdo ilustrativo.

Página de exemplo sobre captura de áudio no navegador. O exemplo lateral usa a API padrão navigator.mediaDevices.getUserMedia dos navegadores.

Requisitos

  • Navegador com suporte a WebRTC.
  • Página servida via HTTPS (ou localhost).
  • Permissão do usuário para usar o microfone.

Referência externa: WebRTC API (MDN).
